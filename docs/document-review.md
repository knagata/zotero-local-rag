# 紙面と抽出結果の確認・修正

管理画面の「資料デバッグ」から専用ページを開きます。問題のある資料を選ぶと、
原本PDFと、その物理ページに対応する抽出チャンクが横並びで表示されます。
「問題のある資料のみ」を外すと、管理されている他のPDFも選べます。

1. PDFページを移動し、紙面を見ながら文字起こしを修正します。
2. 目次を直す場合は「現在の目次を修正案へコピー」して編集するか、チャンクの
   「ここから見出し」で境界を追加し、階層と名称を指定します。
3. 「下書きを保存」を押し、「差分を確認」で修正前後を読みます。
4. 「保存済み修正をDBへ反映」を押します。初回は差分確認になり、もう一度押して
   確認すると反映処理と全DB監査が始まります。進捗は「処理状況へ戻る」で確認します。

下書きの保存では検索結果は変わりません。DBへの反映では、本文の変更部分をローカルで
再埋め込みします。OCR・LLMへの送信や課金はありません。階層要約は再生成待ちになります。
監査が合格し、検索への公開が完了してから修正が通常の検索へ反映されます。

## 間違えたとき

「編集履歴」には保存日時、保存者、修正前後の本文・目次が残ります。
「この修正前に戻す案」または「この修正案を復元」は、新しい版の下書きを作ります。
過去の履歴を消さず、復元した内容も差分確認後に反映できます。
選んだ版で変更した箇所以外の、後の修正は自動で取り消しません。
「修正案をダウンロード」から最新の下書きも保存できます。

原本PDFは変更しません。ZoteroでPDFを差し替えたり、強制再取込したりすると、
DB上の手動修正は上書きされる場合があります。編集履歴は残りますが、異なる原本の修正は
自動では適用しません。紙面と現在の抽出結果を再確認してください。

原本が未同期、Zoteroに接続できない、他の画面で下書きが更新された、といった場合は
理由を表示して停止します。同期や既存処理の完了を待ち、ページを開き直してください。
