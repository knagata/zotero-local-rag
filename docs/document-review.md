# 紙面と抽出結果の確認・修正

管理画面の「資料デバッグ」から専用ページを開き、「資料を選択」でPDFを選びます。
「問題のある資料のみ」を外すと、管理されている他のPDFも選べます。
資料一覧は選択後に閉じ、左側に紙面、右側に修正作業を表示します。

## PDFを確認する

最初は1ページ全体が表示領域に収まります。画面全体をスクロールせず、下部の操作欄から
「幅に合わせる」や倍率指定に変更できます。拡大するとPDF表示領域の中だけをスクロールします。

紙面の右端にカーソルを移すと次ページ、左端では前ページの矢印が表示されます。
タッチ操作では矢印が常に表示されます。下部のPDFページ番号で直接移動することもできます。
左右キーでも移動できますが、文字入力中にはページを切り替えません。

## 修正する

右側のタブで作業を切り替えます。タブやページを切り替えても編集内容は保持します。
長い本文・目次・履歴は、その欄の中だけをスクロールします。保存ボタンは常に下部にあります。

- **本文**：表示中のPDFページに対応するチャンクの文字起こしを修正します。
- **目次**：文書全体の見出し名・階層・開始PDFページを直接編集します。
  「見出しを追加」で新しい行を作れます。紙面に目次ページがなくても構いません。
  同じページに複数の見出しがある場合は「ページ内の開始位置」を選び、
  必要に応じて本文側の「この位置を見出しに」も使えます。「紙面へ」で該当ページを確認します。
  未抽出ページを指定した目次案は保存できますが、DB反映前に開始位置の修正が必要です。
- **注・参考文献**：注や参考文献の文字起こしと分類を修正します。
  指定ページ範囲を参考文献・巻末注・脚注・本文へ分類するか、チャンクごとに指定します。
  本文と脚注が混在するページではチャンク単位で変更してください。
  注・参考文献のページボタンから紙面へ移動できます。
- **差分**：修正前後の本文・目次・分類を確認します。
- **履歴**：保存した版を確認・復元します。

「下書き保存」の後、「差分確認・DB反映」を押します。初回は差分確認になり、もう一度
押して確認すると反映処理と全DB監査が始まります。進捗は上部の「処理状況」で確認します。
下書きの保存では検索結果は変わりません。

DBへの反映では、本文の変更部分をローカルで再埋め込みします。
OCR・LLMへの送信や課金はありません。階層要約は再生成待ちになります。
参考文献・注の本文や分類が変わった場合はCitation Networkも更新待ちになりますが、
自動で外部処理を開始しません。監査が合格し、検索への公開が完了してから
修正が通常の検索へ反映されます。

分類が既存の文書構造検査と一致しない場合は、反映前に停止します。
たとえば資料全体を参考文献にすると保護検査に抵触する場合があります。
分類を黙って変更せず、対象範囲と見出しの確認を案内します。

## 間違えたとき

「履歴」には保存日時（UTC）、保存者、修正前後の本文・目次・分類が残ります。
「この修正前に戻す案」または「この修正案を復元」は、新しい版の下書きを作ります。
過去の履歴を消さず、復元した内容も差分確認後に反映できます。
選んだ版で変更した箇所以外の、後の修正は自動で取り消しません。
「書き出し」から最新の下書きも保存できます。

原本PDFは変更しません。ZoteroでPDFを差し替えたり、強制再取込したりすると、
DB上の手動修正は上書きされる場合があります。編集履歴は残りますが、異なる原本の修正は
自動では適用しません。紙面と現在の抽出結果を再確認してください。

原本が未同期、Zoteroに接続できない、他の画面で下書きが更新された、といった場合は
理由を表示して停止します。同期や既存処理の完了を待ち、ページを開き直してください。
